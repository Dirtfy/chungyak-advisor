# 11. UI 리디자인 (pillyze 레퍼런스, 파란 브랜드)

## 방향
- 레퍼런스: 필라이즈(pillyze) — 옅은 회색 바탕 위에 흰색 둥근 카드, 큰 굵은 제목, 숫자 강조, 그림자 대신 면 구분, 칩/배지로 상태 표시.
- 브랜드 컬러: 파랑 `#2F6BFF`(primary). 보조 옅은 파랑 `#EAF1FF`(primaryContainer).
- 판정 색: 가능 = 파랑, 확인 필요 = 주황 `#F08A00`(tertiary), 불가 = 회색(outline). 규제지역 배지 = 빨강 계열(error).
- 바탕 `#F4F6F9`, 카드 `#FFFFFF`, 본문 `#191F28`, 보조 글자 `#6B7684`. 다크 테마는 같은 구조로 어두운 면.
- 모양: 카드 모서리 20dp, 버튼·칩 12dp, 카드 테두리·그림자 없음(바탕색 대비로 구분).
- 글꼴: 시스템 글꼴 유지(용량·라이선스 부담 없음). 제목은 굵게(Bold/SemiBold), 크기 단계를 줄여 위계를 분명히.

## 단계
1. (v0.6.1 이후 첫 단계) 테마: 색·모양·타이포 → 앱 전체에 자동 반영. 목록 화면: 공고 카드(배지·D-day·핵심 숫자) 재구성. 상세 화면 상단 요약 카드.
2. 상세 화면 나머지(분양가·경쟁률 표를 카드형 행으로), 위치 카드 스타일 정리(지도 규칙 유지: 지도 안엔 OSM 표기만, 문구·버튼은 지도 아래).
3. 내 조건(ProfileScreen)·설정을 별도 화면 + 하단 탭(공고 / 내 조건 / 설정)으로.
4. 빈 상태·오류 상태 일러스트/아이콘, 앱 아이콘 파란 브랜드로 교체.

## 지켜야 할 규칙
- 위치 카드 배치 규칙(docs/08, v0.6.1): 버튼·설명 문구는 지도 아래 별도 줄, 지도는 clip. LocationCardLayoutTest가 360dp·글꼴 1.3배에서 겹침을 검사한다.
- 기능·데이터는 건드리지 않는다(화면만). 키는 사용자가 설정에서 입력.
