# 07. 개인화 — 내 조건 매칭 (v0.5.0)

## 무엇을 하나
- 앱 상단 **내 조건**에서 프로필(거주지·세대주·주택 수·혼인·자녀·청약통장·소득 % 등)을 입력.
- 공고마다 **신청 가능 / 확인 필요 / 불가**를 판정하고, 상세 화면에 공급 유형별 이유를 보여 줌
  (일반공급 1순위, 신혼부부·생애최초·다자녀·노부모부양·신생아 특공).
- 알림: 프로필이 있으면 알림 범위(모든 공고 / 가능만 / 가능+확인 필요, 기본값 가능+확인 필요)에 맞는 공고만 알림.
  프로필이 없으면 예전처럼 모든 신규 공고를 알림.

## 규칙 근거
- 「주택공급에 관한 규칙」(국토교통부령), 청약홈 청약자격·특별공급 안내
  (https://www.applyhome.co.kr/ar/ara/selectSubscrptIntroSpetialView.do), 찾기쉬운 생활법령(easylaw.go.kr).
- 기준일: `Eligibility.RULES_DATE` = 2026-10-03. 제도가 바뀌면 `match/Eligibility.kt`의 상수와 기준일을 고친다.
- 주요 값
  - 1순위 가입기간: 규제지역 24개월, 그 밖의 수도권 12개월. 국민주택 납입 횟수는 24회(규제) 또는 12회.
  - 민영 예치금(만원, 거주지 기준; ≤85 / ≤102 / ≤135 / 그 초과㎡): 서울 300/600/1000/1500, 인천 250/400/700/1000, 경기 200/300/400/500.
  - 규제지역 1순위: 세대주여야 함, 5년 내 당첨 이력 없음, 민영은 1주택 이하.
  - 특공 공통: 무주택, 평생 1회.
  - 신혼부부(혼인 7년 이내)
    - 민영: 소득 140%(맞벌이 160%) 이하. 넘으면 추첨 물량에 지원하되 부동산 3억3,100만원 이하.
    - 공공: 130%(맞벌이 140%).
  - 생애최초: 1순위, 소득세 5년 납부.
    - 민영: 160%.
    - 공공: 130%, 저축액 600만원.
  - 다자녀: 미성년 자녀 2명 이상.
  - 노부모부양: 세대주, 1순위.
  - 신생아: 140%(맞벌이 150%).
- 판정하지 않는 항목(공고문 확인 필요): 기관추천, 청년, 이전기관, 가점 점수, 자산 세부(자동차 등), 지역별 거주기간 세부 예외.
- 입력하지 않은 항목은 "확인 필요"로 판정한다. 공고의 주택 구분(민영/국민)을 알 수 없으면 "신청 가능"이 아니라 최대 "확인 필요"로 판정한다.

## 개인정보
- 프로필은 기기 안의 별도 SharedPreferences(`chungyak_profile`)에만 저장한다. 어디로도 전송하지 않는다.
- Android 자동 백업(backup_rules.xml / data_extraction_rules.xml)과 앱의 백업 파일 내보내기에서도 제외한다.

## v0.5.1 — 청약통장 가입 일자로 기간 자동 계산
- [내 조건] → 청약통장: 가입 일자를 날짜 선택기로 입력한다(미래 날짜는 선택 불가). 화면에 오늘 기준 기간을 바로 보여 준다(예: "7년 6개월 (90개월)").
- 판정할 때마다 그 공고의 모집공고일 기준으로 다시 계산한다(`Eligibility.evaluate` → `Profile.accountMonthsAt`). 저장한 시점의 값으로 고정하지 않는다.
  공고일을 읽을 수 없으면 오늘을 기준으로 한다.
- 계산 규칙(`match/AccountPeriod.kt`)
  - 가입일부터 공고일까지 만 개월로 센다. 다음 달의 같은 날이 되어야 1개월이다.
  - 같은 날이 없는 달은 그 달 말일에 1개월이 찬다(예: 1/31 가입 → 2/28, 윤년이면 2/29).
- 기간 직접 입력(개월)도 그대로 둔다. 둘 다 있으면 가입 일자로 계산한 값이 우선한다.
  기존에 저장한 프로필(직접 입력값)은 그대로 읽힌다. 새 필드 `accountOpened`가 없으면 빈 값으로 둔다.
- 저장 위치는 그대로다(기기 안 `chungyak_profile`, 백업 제외).
- 테스트: `AccountPeriodTest`(월말·윤년·연말 경계), `ProfileStoreTest`(저장·복원, v0.5.0 저장값 보존), `EligibilityTest`(공고일에 따라 1순위 여부가 바뀜).
