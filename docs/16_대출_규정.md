## 1. 규정 요약 (은행권 주택구입 주담대, 2026-10-10 시행 중인 것)

### 1-1. LTV (주택담보인정비율) — 10·15 대책(2025.10.15 발표, 10.16 시행) + 6·27 대책(2025.6.27)
| 차주 | 규제지역(투기과열·조정) | 수도권 비규제 | 지방 비규제(참고) |
|---|---|---|---|
| 무주택 | **40%** | 70% | 70% |
| 서민·실수요자(무주택세대주 + 부부합산 연소득 9천만원 이하 + 주택가격 8억 이하) | **60%** | 70% | 70% |
| 생애최초 | **70%** (6개월 내 전입 의무) | 70% | 80% |
| 1주택(기존 집 처분조건부) | 40% | 70% | 70% |
| 1주택(처분 안 함) | **0% (구입 주담대 금지)** | 0% | 70% |
| 2주택 이상 | **0%** | 0% | 60% |

### 1-2. 주담대 금액 상한
| 대상 | 상한 |
|---|---|
| 규제지역, 시가 15억 이하 | **6억** |
| 규제지역, 15억 초과 ~ 25억 이하 | **4억** |
| 규제지역, 25억 초과 | **2억** |
| 수도권 비규제 | 6억 (6·27) |
| 지방 비규제 | 없음 |

- 분양 아파트: 중도금 집단대출에는 6억 상한·DSR이 적용되지 않고, **입주 때 잔금대출로 바꿀 때** 위 상한·LTV·DSR이 적용된다.
- 경과규정(입주자모집공고일 기준): ~2025.6.27 공고 = 종전 규정, 6.28~10.15 = 6억 상한, 10.16~ = 단계별 상한 + LTV 40%.

### 1-3. DSR (총부채원리금상환비율)
- 은행권 한도 **40%** (은행업감독규정 별표6). 2금융권 50%.
- 스트레스 DSR 3단계(2025.7.1~): DSR을 계산할 때 금리에 가산금리를 더한다. 수도권·규제지역 주담대는 하한이 **3.0%p**(2025.10.16~), 지방은 2단계(0.75%p) 유지.
- 금리 유형별 반영 비율: 변동 100%, 5년 혼합형 80%, 5년 주기형 40%, 만기 고정 0%.
- 연 원리금 산정(금융위 DSR 산정 방식):
  - 분할상환(원리금·원금균등): 실제 상환액. 거치기간은 빼고 원금 상환 기간으로 본다.
  - 만기일시: 대출총액 ÷ 대출기간(최대 10년) + 연 이자.
  - 체증식(주금공 기준): 초기 10년 원리금의 연평균(상환기간 10년 이하면 5년).

### 1-4. 분양 대금 흐름
계약금(보통 10~20%, 현금) → 중도금(보통 60%, 시행사 알선 집단대출, HUG 보증 — 2023.3.20부터 분양가 9억 상한·1인 5억 한도 폐지, 규제지역 집단대출 LTV 40%) → 잔금(입주 때 중도금대출을 잔금대출로 전환, 위 규정 전부 적용).

### 1-5. 상환 방식 (예: 3억, 연 4%, 30년)
| 방식 | 첫 달 | 마지막 달 | 총이자 | DSR 연 상환액 |
|---|---|---|---|---|
| 원리금균등 | 143.2만 | 143.2만 | 2억 1,561만 | 1,719만 |
| 원금균등 | 183.3만 | 83.6만 | 1억 8,050만 | 1,602만 |
| 체증식(연 1% 증가 근사) | 126.6만 | 170.5만 | 2억 3,095만 | 1,597만(초기 10년 평균) |
| 만기일시 | 100만(이자) | 3억 100만 | 3억 6,000만 | 4,200만(원금÷10년 + 이자) |
| 원리금균등 + 거치 1년 | 100만(이자) → 145.8만 | 145.8만 | 2억 1,936만 | 1,750만 |

- 체증식: 만 40세 미만 등 주금공(보금자리론) 조건, 사전심사. 정부 예시(3억·40년·4.6%): 첫 달 약 20만원·첫해 228만원 덜 내고 총이자 약 3,800만원 더 냄 → 증가율 1.0%/년이 가장 가깝다(첫 달 18.7만·첫해 217만 덜, 총이자 3,962만 더).
- 수도권·규제지역 주담대 만기 30년 이내(6·27). 거치기간은 보통 1년 이내.

### 1-6. 규제지역 목록 (2026-07-01 기준)
서울 25개 구 전부. 경기: 과천, 광명, 성남, 의왕, 하남, 구리, 수원 영통·장안·팔달, 안양 동안, 용인 수지·기흥, 화성 동탄.

## 2. 앱 계산
쓸 수 있는 대출 = **min(LTV × 분양가, 주담대 금액 상한, DSR 한도 원금, 입력한 대출 한도, 월 상환 상한으로 갚을 수 있는 원금)**.
가장 작은 것이 "걸린 제약"으로 화면에 나온다(예: "대출 최대 ○억 — DSR 40%에 걸림").

- 지역: 공고의 투기과열지구·조정대상지역 표시가 있거나, 주소가 1-6 목록에 있으면 규제지역(둘 중 하나라도 — 보수적).
- DSR 한도 원금 = (연소득 × 40% − 기존 대출 연 상환액) ÷ (1억을 '금리 + 스트레스 가산금리'로 빌렸을 때 DSR 연 상환액) × 1억.
- 판정: 분양가 − 현금 > 쓸 수 있는 대출 → **불가**. 입주 전 현금(계약금 + 중도금 중 집단대출이 안 되는 몫)이 모자라거나 여유가 분양가의 5% 미만 → **빠듯**. 그 밖 → **가능**.
- 중도금 집단대출 = 분양가 × min(60%, LTV). 예: LTV 40%면 중도금 60% 중 20%는 현금.

## 3. 새 입력 (내 조건 → 자금, 기기 안에만 저장·백업 제외)
| 항목 | 키 | 기본 |
|---|---|---|
| 연소득(세전, 공동 대출이면 부부 합산) | `incomeManwon` | 미입력(-1) → DSR 미반영 |
| 기존 대출 연 원리금 | `debtAnnualManwon` | 미입력(0으로 봄) |
| 기존 집 처분 조건(1주택일 때만 보임) | `sellingHome` | 꺼짐 |
| 상환 방식: 원리금균등·원금균등·체증식·만기일시 | `repayment` | 원리금균등 |
| 거치기간(년, 만기일시면 숨김) | `graceYears` | 0 |
| 금리 유형: 변동·혼합·주기·고정 | `rateType` | 혼합형 |

주택 수·생애최초는 '세대·주택'(`homesOwned`, `everOwned`), 세대주는 `householdHead` 입력을 그대로 쓴다.
v0.11.0 이전 프로필은 위 기본값으로 읽힌다. 프로필은 prefs JSON이라 Room DB 변경 없음(마이그레이션 불필요).

## 4. 해석이 애매해 임의로 정한 것 (오너 확인 필요하면 LoanRules.kt만 고치면 됨)
1. 담보가치 = 분양가(감정가·KB시세 아님).
2. 소득 입력 하나를 DSR과 서민·실수요자(부부합산 9천만원) 판정에 같이 쓴다.
3. 규제지역 = 공고 표시 **또는** 현재 지정 목록(보수적). 공고일 기준 경과규정은 반영하지 않음(현재 규정으로 계산).
4. 스트레스 가산금리는 수도권 하한 3.0%p × 금리 유형 비율. 기본 금리 유형은 혼합형(80% → 2.4%p).
5. 만기는 수도권에서 30년으로 자른다(입력이 40년이어도).
6. 월 상환 상한과 비교하는 '대표 월 상환액': 원리금균등 = 매달, 원금균등 = 원금 상환 첫 달(최대), 체증식 = 초기 10년 평균, 만기일시 = 이자.
7. 은행권 DSR 40%만. 2금융권 50%, 신용대출 1억 규제는 반영 안 함.
8. 정책대출(디딤돌·보금자리론·신생아 특례)은 범위 밖: 소득·자산·가격 자격과 한도·금리가 상품마다 달라 별도 흐름이 필요. 화면 안내 문구에서만 언급.
9. 1주택(처분 안 함)·다주택은 수도권에서 '대출 불가'. 처분조건부 1주택은 무주택과 같은 LTV.
10. 중도금 비율 60% 고정, 집단대출은 LTV까지만 된다고 본다.
