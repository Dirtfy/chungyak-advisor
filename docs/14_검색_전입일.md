# 14. 공고 검색 · 거주지 전입일 · 진행바 점 제거 (v0.10.0)

오너가 v0.9.0을 써 보고 준 피드백 3가지를 한 번에 반영했다.

## 1. 진행바 오른쪽 끝 점 제거

Material3 1.3의 `LinearProgressIndicator`(진행률 표시형)는 트랙 오른쪽 끝에 작은 점(stop indicator)을 그린다.
`drawStopIndicator = {}`를 넘겨 끈다. 채워진 부분·트랙 모양(두께·간격·색)은 그대로다.

적용한 곳(진행률 표시형 전부):
- 온보딩 상단 진행바 (`OnboardingScreen`) — 1/8 ~ 8/8
- 가점 카드의 항목별 막대 (`GajeomCard`) — 무주택기간·부양가족·통장 가입기간
- 업데이트 다운로드 진행바 (`UpdateDialog`). 다운로드 준비 중의 무한 진행바(indeterminate)는 원래 점이 없다.

## 2. 현 거주지 전입일

- 예전: "현 거주지 연속 거주 기간(개월)" 숫자 입력 → 시간이 지나도 값이 그대로였다.
- 이제: **"현 거주지 전입일"** 을 날짜 선택기로 고른다(통장 가입일과 같은 방식, 미래 날짜는 고를 수 없음).
  아래에 "약 N년 M개월 거주 · 오늘 기준" 표시.
- 판정(`Eligibility.evaluate`)은 매번 **공고일 기준**으로 전입일부터 개월 수를 다시 계산한다
  (`Profile.residenceMonthsAt`). 판정 근거에 "거주 … — 전입일 …, 공고일 … 기준" 메모가 붙는다.
- 온보딩 1단계(거주)와 '내 조건' 탭이 같은 입력칸을 쓴다.

### 예전 값 이전(덮어쓰기 설치)
- `ProfileStore.profile`을 읽을 때 `residenceSince`가 비어 있고 예전 `residenceMonths = N(≥0)`이 있으면
  전입일 = **오늘 − N개월**(근사값)로 한 번 바꿔 저장한다(`ProfileStore.migrateResidence`). 바꾼 날에는 판정 결과가 같고,
  이후엔 기간이 자동으로 늘어난다. 정확한 날짜는 '내 조건'에서 고치면 된다.
- 미입력(-1)이면 그대로 비워 둔다 → 거주기간이 필요한 판정은 이전처럼 "공고 확인".
- 저장 형식은 같은 prefs 키(`profile_v1`)의 JSON에 `residenceSince` 필드를 더한 것뿐이라 다른 값은 그대로 남는다.

## 3. 공고 검색

- **어디서**: 공고 탭 맨 위(앱 바 바로 아래) 검색창. 목록을 스크롤해도 남는다. 공고가 하나도 없으면 숨김.
- **무엇을**: 이 폰에 수집된 공고 안에서(서버·API 호출 없음)
  **단지명 · 공급 위치(주소, 시·군·구·동) · 지역(서울/경기/인천) · 사업주체(시행사) · 시공사**.
- **어떻게**: 입력할 때마다 바로 거른다. 부분 일치, 대소문자·띄어쓰기 무시, 여러 낱말이면 모두 들어 있어야 함
  (예: "래미안 서초", "원베일리", "수원", "현대건설").
- 기존 '가능·확인 필요만 보기' 필터와 함께 적용되고(필터 → 검색), 정렬(추천순 등) 순서는 그대로다.
- 결과가 없으면 "'검색어' 검색 결과가 없어요" + [검색어 지우기].
- 검색어는 화면 상태(저장 안 함) — 상세를 열었다 돌아와도 남고, 앱을 다시 켜면 비어 있다.
- 공고 상세 요약 카드에 사업주체·시공사 줄을 추가(값이 있을 때만).

### 사업주체·시공사 수집 (DB v6)
- 청약홈 APT 분양정보 응답의 `BSNS_MBY_NM`(사업주체명) → `Notice.builder`,
  `CNSTRCT_ENTRPS_NM`(건설업체명·시공사) → `Notice.contractor`.
- Room v5 → v6 `MIGRATION_5_6`: `ALTER TABLE notices ADD COLUMN … TEXT NOT NULL DEFAULT ''` 두 개(추가만, 데이터 보존).
- 이미 수집된 공고는 빈 값으로 시작하고, 다음 폴링(6시간 주기 또는 [지금 확인])에서 `updateMeta`로 채운다.
  그 전까지는 단지명·주소·지역으로만 검색된다.
- 백업 JSON에도 두 필드 포함(예전 백업은 빈 값으로 가져옴).
- 스키마 JSON(`app/schemas/…/6.json`)은 서버에서 빌드하지 않으므로 CI가 `room-schemas` 아티팩트로 올린 것을 받아 커밋한다.
