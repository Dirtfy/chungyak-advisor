# 15. 내 자금으로 살 수 있나 — 매매 가능 판정 (v0.11.0)

> v0.12.0: 대출액 계산에 LTV·주담대 금액 상한·DSR(스트레스)·체증식/만기일시/거치를 반영했다 → [docs/16](16_대출_규정.md). 아래는 v0.11.0 당시 설계.

오너 요청(2026-10-10): "사용자 현재 현금 + 대출 가능. 여기에 대출 받았을 때 매달 나가는 비용 상한은 유저가 정하고."

## 입력 (내 조건 탭 → '자금' 묶음, 맨 아래)
모두 만원 단위, 기기 안에만 저장(프로필과 같은 prefs `profile_v1` JSON — 자동 백업·백업 파일 제외).

| 항목 | 키 | 기본 | 비고 |
|---|---|---|---|
| 보유 현금(가용 자본) | `cashManwon` | 미입력(-1) | **이게 있어야 판정**. 없으면 판정을 숨기고 입력 안내 |
| 대출 가능 한도 | `loanLimitManwon` | 미입력 | 은행·앱에서 조회한 금액 |
| 월 상환액 상한 | `monthlyCapManwon` | 미입력 | 사용자가 정함 |
| 대출 금리(연 %) | `loanRatePct` | 4.0 | 가정값, 소수 입력 |
| 상환 기간(년) | `loanYears` | 30 | 1~50 |
| 상환 방식 | `repayment` | 원리금균등 | 원금균등은 첫 달(가장 큰 달) 기준 |
| 계약금 비율(%) | `downPaymentPct` | 10 | 현금으로 내야 하는 몫 |

입력하는 대로 아래에 "구매 가능 자금 = 현금 + 대출"과 대출이 어떻게 정해졌는지 바로 보여 준다.
설정 탭에도 '내 자금' 카드(요약 + [자금 입력하기/고치기])가 있다. 온보딩(8단계)에는 넣지 않았다(선택 항목).
v0.10.0 이전에 저장된 프로필은 자금 미입력 + 기본 가정값으로 읽힌다(다른 값 그대로).

## 계산 (`match/Affordability.kt`)
- 월 상한으로 감당 가능한 원금
  - 원리금균등: `L = P × (1 − (1+r)^−n) / r` (r = 연금리/12, n = 기간×12, r=0이면 P×n)
  - 원금균등(첫 달 기준): `L = P / (1/n + r)`
- **실제 쓸 대출 = min(대출 한도, 월 상한으로 감당 가능한 원금)**. 한쪽만 넣으면 그쪽, 둘 다 없으면 0(현금만).
- **구매 가능 자금 = 현금 + 실제 쓸 대출**.
- 예: 현금 3억, 한도 5억, 월 200만원(연 4%·30년·원리금균등) → 월 200만원으로 약 4억 1,892만원 → 구매 가능 자금 7억 1,892만원.

## 판정 (주택형별 분양최고금액 기준)
| 상태 | 조건 |
|---|---|
| 불가 | 분양가 − 현금 > 실제 쓸 대출 → **부족액** 표시 |
| 빠듯 | 살 수는 있지만 ① 계약금(분양가×비율)을 현금으로 못 내거나 ② 남는 돈이 분양가의 5% 미만(취득세·등기·이사 등 부대비용 몫) |
| 가능 | 그 밖 |

필요한 대출(분양가 − 현금)의 **예상 월 상환액**을 함께 보여 준다.
청약홈 API에는 계약금·중도금 비율이 없어서 계약금 비율은 사용자 가정값(기본 10%)이다. 중도금은 집단대출, 잔금은 현금+대출로 낸다고 본다.
주택형별 정보를 아직 못 받은 공고는 공고의 최저·최고 분양가로 판정한다. 분양가 정보가 없으면 판정 없음.

## 표시
- **공고 목록**: 카드 아래 "내 자금: …" 한 줄(내 조건 판정 줄과 같은 모양, 색 = 가능 파랑 / 빠듯 주황 / 불가 빨강).
  - 모두 같은 상태: "가능 · 대출 3억 · 월 약 143만원"
  - 일부만: "일부 가능 · 분양가 7억 이하 주택형"
  - 모두 불가: "불가 · 최저가 기준 4.5억 부족"
  - 자금 미입력이면 줄은 숨기고, 목록 머리에 "내 자금을 넣으면 공고마다 살 수 있는지 보여 드려요 〉" → 내 조건 탭의 자금 묶음으로 바로 스크롤.
- **공고 상세**: 가점 카드 아래, 분양가 카드 위에 "내 자금으로 살 수 있나" 카드 — 구매 가능 자금, 대출 근거,
  주택형별 [분양가 · 가능/빠듯/불가 배지 · 필요한 대출·월 상환액·부족액]. 미입력이면 [내 자금 입력하기].
- **새 공고 알림**: 펼친 알림에 "내 자금: …" 줄 추가(자금 입력 시).
- 앱 안 안내 문구: 입력값 기반 추정이며 실제 대출 심사(LTV·DSR·소득·규제지역·중도금 집단대출 조건)와 다를 수 있음, 옵션·발코니 확장비 제외.
