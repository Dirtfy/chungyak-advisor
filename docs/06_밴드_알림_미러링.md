# 06. 스마트밴드(Galaxy Fit3) 알림 미러링 (v0.4.3~)

Fit3 는 서드파티 앱 설치 불가 → 폰의 Galaxy Wearable 이 폰 알림을 미러링. 앱은 "미러링 가능한 일반 알림"만 게시한다.

## 알림 게시 경로 점검 (v0.4.2 기준)
| 경로 | 결과 |
|---|---|
| `Notifier.notifyNew` (CheckWorker 에서 신규 공고 시) | 유일한 경로. 공고당 1건(최대 5) + 6건 이상이면 요약 1건 |
| 포그라운드 서비스 / ongoing / 풀스크린 / 알람 / 진동만 | 없음 (WorkManager 는 setForeground 미사용) |
| setLocalOnly(true) / 그룹 요약만 | 없음 |
| 채널 `new_notices` | IMPORTANCE_HIGH 이지만 **진동 미지정**, 카테고리 없음, 요약 알림은 우선순위 기본 |

→ 코드상 미러링을 막는 형태는 없었고, 밴드가 조용했던 주원인은 Galaxy Wearable 설정(사이드로드 앱은 "앱 알림" 목록에서
기본 꺼짐, "휴대전화 사용 중 알림 표시 안 함")일 가능성이 높다. 진동 미지정 채널은 밴드에서 진동이 약하거나 없을 수 있어 함께 보강.

## 변경
- 새 채널 `new_notices_v2`: IMPORTANCE_HIGH, 진동 패턴 0/400/200/400, 잠금화면 공개. 진동은 채널 생성 후 못 바꾸므로 새 ID.
  예전 채널을 사용자가 꺼 두었으면(IMPORTANCE_NONE) 새 채널도 꺼진 채로 생성, 예전 채널은 삭제.
- 모든 알림: ongoing=false, setLocalOnly(false), CATEGORY_RECOMMENDATION, PRIORITY_HIGH, 진동, 공개 표시.
- 밴드용 짧은 문구: 제목 `신규 청약 {단지명 18자}`, 본문 `{지역} · 1순위 {날짜}`. 상세는 폰의 펼친 알림(BigText).
- 테스트: `NotifierTest` (Robolectric).

## 청약 일정 알림 (v0.7.0)
- 대상: 새 공고 알림과 같은 기준 — 내 조건이 있으면 알림 범위(가능만 / 가능·확인 필요 / 전체)와 관심 조건(지역·분양가·면적)으로 거른 공고, 없으면 전체.
- 일정: 1순위 접수 시작일(`rank1Start`), 당첨 발표일(`resultDate`).
- 시각: 전날 18~22시에 한 번. 전날을 놓치면 당일 8~22시에 한 번. 밤(22~8시)에는 보내지 않음. 같은 공고·같은 일정은 한 번만(보낸 기록은 설정에 저장, 7일 지난 기록은 정리).
- 실행: `ScheduleAlertWorker` 1시간 주기(네트워크 없음, 기기 DB만 읽음) + 공고 확인(CheckWorker) 직후. OS가 묶어서 늦출 수 있어 시각은 대략적.
- 채널·형태: 새 공고 알림과 같은 채널(`new_notices_v2`, 높은 중요도·진동) → 밴드로 같은 경로로 전달. 제목 예 "내일 접수 단지명…", 본문 "경기 · 내일(2026-10-07) 1순위 접수".
- 설정 탭 > 알림 > '청약 일정 알림'으로 켜고 끔(기본 켬). 로직은 `notify/ScheduleAlerts.kt`, 테스트 `ScheduleAlertsTest`.
